# 숙향식 가치분석 (개인용)

종목명을 넣으면 DART 공시로 최근 10년 재무, 숙향의 네 가지 조건, 숙향식 내재가치, 할인율·상승여력을 계산하고
Markdown 리포트로 내려받습니다. 최종 등급(매수 검토 후보 / 관찰 대상 / 기준 미달 / 자료 부족)은 직접 고릅니다.

## 처음 한 번만

1. Python 3.10 이상 설치 (python.org)
2. DART 인증키 발급: https://opendart.fss.or.kr → 인증키 신청 (무료, 이메일 인증)
3. 이 폴더에서 터미널을 열고:

    pip install -r requirements.txt

4. (선택) `.streamlit/secrets.toml.example`을 `secrets.toml`로 이름을 바꾸고 인증키를 넣기

## 실행

`실행.bat`을 더블클릭합니다(패키지가 없으면 처음 한 번 자동 설치). 터미널에서 직접 실행하려면:

    streamlit run app.py

브라우저가 열리면 사이드바에 예금금리와 조회일을 넣고, 종목명을 검색해 분석합니다.
분석 뒤에 사이드바 설정(예금금리, 주가 직접 입력, 리스부채 등)을 바꾸면 자동으로 다시 계산합니다.
처음 분석은 DART 호출이 30회 정도라 1분가량 걸리고, 지난 연도 자료는 이 폴더의 `.dart_cache`에 저장돼 다음부터 빠릅니다.
저장된 자료는 90일이 지나면 다시 받습니다. 정정공시를 바로 반영하려면 사이드바의 '캐시 비우고 새로 받기'를 누르세요.

## 파일과 주식 스크리너 연결

- `app.py`: 페이지 설정과 사이드바(인증키)만 두고 화면은 `sukhyang_ui.py` 를 부릅니다.
- `sukhyang_ui.py`: 검색·분석·결과 화면. 주식 스크리너(`Desktop\CLAUDE\stock-screener`)의 '숙향 정밀분석' 화면과 종목 탭도
  이 파일을 그대로 불러 쓰므로, 여기를 고치면 두 앱에 같이 반영됩니다.
- `sukhyang.py`(계산), `data.py`(DART 조회·계정 분류)도 스크리너가 함께 씁니다.

## 휴대폰·외부에서 쓰기 (Streamlit Community Cloud, 무료)

1. GitHub에 **Private** 저장소를 만들고 이 폴더를 올립니다. `.gitignore` 덕분에 `secrets.toml`과 `.dart_cache`는 올라가지 않습니다.
2. https://share.streamlit.io 에 GitHub 계정으로 로그인 → **Create app** → 저장소 선택, Main file path는 `app.py`.
3. **Advanced settings → Secrets**에 아래를 넣고 Python 버전은 3.11을 고릅니다(패키지 버전은 requirements.txt에 고정).

        DART_API_KEY = "발급받은_인증키"
        DEPOSIT_RATE = 2.5   # 선택: 사이드바 예금금리 기본값(%)

4. 배포 후 앱 **Settings → Sharing**에서 본인만 볼 수 있게 설정합니다.

클라우드에서는 주가 자동 조회가 막힐 수 있고(그때는 직접 입력), 서버가 재시작되면 `.dart_cache`가 비워져 첫 분석이 다시 1분쯤 걸립니다.
`secrets.toml`이나 Secrets에 키를 넣으면 키는 화면에 표시되지 않고 서버에서만 쓰입니다.

## 파일 구성

- `app.py` 화면
- `sukhyang.py` 지침의 계산식(가중평균 EPS, 내재가치, 할인율, 상승여력), 네 가지 조건 판정, 장기 검증, 리포트
- `data.py` DART 조회, 계정 찾기, 순현금 분류, 주가 조회

## 내재가치 기준 (사이드바에서 선택)

- **최근 4분기 TTM (기본값)**: 최신 분기보고서까지 반영합니다. 예) 2026년 반기보고서가 최신이면
  EPS 구간은 2025.07~2026.06, 2024.07~2025.06, 2023.07~2024.06 (구간이 겹치지 않게 1년씩 밀어 3:2:1 가중평균),
  BPS는 2026.06월말 자본 ÷ 같은 시점 자사주 제외 주식수. PER·PBR 조건도 같은 기준을 씁니다.
- **연간 사업보고서 (지침 원식)**: 최근 3개 사업연도 EPS와 최근 사업연도말 BPS.
- 고르지 않은 쪽 내재가치도 '참고'로 함께 표시됩니다.

## 알아둘 한계

- 계정과목은 DART 표준계정 ID를 먼저 쓰고, 없으면 계정명으로 찾습니다. 회사마다 이름이 달라 일부 항목이 비거나
  틀릴 수 있으니 리포트의 출처 링크로 원문을 확인하세요.
- 순현금은 계정명으로 자동 분류합니다. 화면의 '순현금 계산 내역'에서 포함된 계정을 꼭 확인하세요.
- 주식수는 DART '주식의 총수 현황'의 합계(보통주+우선주)에서 자기주식을 뺀 값입니다.
- 주가는 FinanceDataReader → pykrx 순으로 조회하고, 실패하면 사이드바에 직접 입력합니다.
- 금융업, 결산월이 12월이 아닌 회사는 결과 해석에 주의가 필요합니다(화면에 안내 표시).
- 특별배당과 일반배당은 자동으로 구분하지 않습니다.
